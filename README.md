# Markdown 实时预览器 📝

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

左侧写 Markdown，右侧实时渲染。内置轻量解析器，无框架、无依赖、无外部请求，单个 HTML 文件双击即可使用。

## ✨ 功能

- **实时渲染**：输入即预览，无延迟
- **语法支持**：标题、加粗 / 斜体 / 删除线、行内代码、代码块、引用、有序 / 无序列表、表格、链接、图片、分割线
- **工具栏**：一键插入标题、加粗、代码、引用、链接、列表、表格
- **导出**：复制渲染后的 HTML、下载 `.md` 文件
- **自动保存**：内容保存在浏览器本地（localStorage），刷新不丢失
- **安全**：HTML 转义，粘贴原始 `<script>` 不会被执行

## 🚀 在线体验

👉 点击打开：<https://sunfloweandnefertari.github.io/markdown-previewer-/>

部署在 GitHub Pages，打开即用，无需安装。

## 🚀 使用

- **方式一**：直接双击 `index.html` 在浏览器打开
- **方式二**：部署到任意静态服务器（GitHub Pages / Gitee Pages / Nginx …）

## 📦 技术

原生 HTML + CSS + JavaScript，Markdown 解析器为手写实现，零依赖。
